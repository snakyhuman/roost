# roost

Десктопное приложение для macOS и Linux над фоновыми сессиями агентов: само находит все сессии, группирует их, показывает родной TUI агента в терминальной панели и управляется с клавиатуры. Наследник cc-fleet (Python TUI). Стек — Qt Quick и C++, эмулятор терминала — libghostty-vt.

## Работа по этапам — главное правило

Проект идёт этапами M0–M7. **После каждого этапа: показать результат, прогнать критерий готовности, показать его вывод — и остановиться.** Следующий этап не начинается без явной отмашки. Это касается и документов, и кода.

| Этап | Что |
|---|---|
| M0 | каркас: CMake с пресетами, Qt 6, сборка libghostty-vt, пустые `roost` и `roostd`, CI на macOS и Linux с гейтами format и tidy |
| M1 | `roostd`: JSON-RPC на unix-сокете, шина событий, хранилище, загрузчик плагинов с бэкенд-процессами |
| M2 | адаптер Claude: сессии из `claude agents --json`, состояния, тёплый пул `claude attach` в PTY |
| M3 | `TerminalItem` на libghostty-vt: разбор в рабочем потоке, render state, ввод, снимок при открытии |
| M4 | окно: QML-плагины, список сессий (категории, пины, архив, непрочитанные), терминал. **Рабочий продукт, паритет с cc-fleet по основному сценарию** |
| M5 | раскладка панелей со связями, keymap и палитра команд из вкладов плагинов |
| M6 | уведомления, PR по worktree, keep-awake, импорт состояния cc-fleet |
| M7 | упаковка: `.dmg` и AppImage |

После M7: адаптеры Codex и OpenCode, удалённый `roostd` через ssh, редактор связей, сторонний плагин как проверка API.

## Документы

Два файла, оба на русском (код и идентификаторы — английские). Переводить будем, если проект станет публичным.

- `docs/prior-art.md` — разбор cc-fleet, libghostty-vt, agterm, herdr, протоколов агентов и UI-стеков: как устроено, где болит, что забираем. Со ссылками `файл:строка` на исходники изучаемых проектов.
- `docs/design.md` — архитектура roost и ADR. Источник истины по решениям; расхождение кода с ним — повод править одно из двух осознанно.

## Стек

- C++23, **только clang** (17+; на macOS — Apple clang из Xcode). Один компилятор — один набор диагностик.
- Qt 6, только модули под LGPLv3: Core, Gui, Qml, Quick, Quick Controls, Network, Test. Линковка динамическая. Модули только под GPL не подключать — список в `docs/design.md`.
- libghostty-vt — из исходников через CMake `FetchContent` на зафиксированном коммите. Нужен Zig ≥ 0.17.1.
- Сборка только через пресеты: `cmake --preset dev`, `ctest --preset dev`. Пресеты: `dev`, `asan-ubsan`, `release`.
- Форматирование — `.clang-format` (google, 4 пробела) для C++, `qmlformat` для QML. Нейминг — `.clang-tidy`, `readability-identifier-naming`.
- Тесты: Qt Test для C++, Qt Quick Test для QML, `QT_QPA_PLATFORM=offscreen`. Тесты не трогают настоящий `~/.config/roost` и `~/.config/cc-fleet`.

## Нейминг

| Что | Как | Пример |
|---|---|---|
| классы | PascalCase | `SessionModel`, `TerminalItem` |
| функции, методы, аргументы, переменные | camelCase | `listSessions`, `sessionId` |
| глобальные константы, `static constexpr` члены | ALL_CAPS | `MAX_WARM_SESSIONS` |
| члены класса | PascalCase, приватные и защищённые с `_` | `Pty_`, публичный `Id` |
| перечисления | префикс `E` | `ESessionState`, значения `ESessionState::Blocked` |
| концепты | префикс `C` | `CAdapter` |
| параметры шаблонов | префикс `T` | `TValue` |
| пространства имён | lower_case | `roost` |
| файлы C++ | snake_case | `session_model.cpp` |
| файлы QML | PascalCase | `SessionList.qml` |

Функции и методы — camelCase, а не PascalCase: свойства, сигналы и `Q_INVOKABLE`-методы, видимые из QML, обязаны начинаться со строчной буквы, а два стиля в одном классе хуже одного.

## Чем roost не является

- Не терминал общего назначения — Ghostty, WezTerm и agterm лучше. Терминальная панель есть только для TUI агентов.
- Не IDE и не замена TUI агента — roost показывает родной TUI, а не свой чат поверх SDK.
- Не мультиплексор — сессии живут в самих агентах или в `roostd`, не в tmux.
- Не кроссплатформа в v1 — macOS и Linux. Windows не в планах.
- Не песочница — плагин видит всё, что видит API, включая транскрипты.

## Компоненты

- `roost` — окно на Qt Quick: оболочка, раскладка, панели плагинов, `TerminalItem`.
- `roostd` — демон на QtCore без GUI: адаптеры агентов, пул PTY, бэкенды плагинов, шина событий, хранилище. Переживает перезапуск окна.
- `plugins/` — встроенные плагины на том же API, что и сторонние.

Инвариант: **окно не держит состояния, которое нельзя восстановить из `roostd`.** Перезапуск окна не теряет ни сессию, ни вывод, ни раскладку.

## Референсы для сверки

Клоны изучённых проектов живут в скратчпаде сессии, а не в репозитории: `ghostty` (libghostty-vt, заголовки `include/ghostty/vt/`), `cc-fleet` (`~/src/cc-fleet`), `agterm`, `herdr`, `waveterm`, `Paradev`, `codex` (`codex-rs/app-server`). Коммиты — в шапке `docs/prior-art.md`. При новой сессии переклонировать при необходимости.
